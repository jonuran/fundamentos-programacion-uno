CAPÍTULO 3 — OPERADORES#

Especialización en Ciencia de Datos — UNO#

Docente: Ing. Jonatan Uran#

Los operadores permiten construir expresiones que combinan valores, variables y funciones. Son fundamentales para realizar cálculos, comparaciones y decisiones dentro de un programa.

En este capítulo veremos:

  • Operadores aritméticos

  • Operadores lógicos

  • Operadores de comparación

  • Prioridad de operadores

  • Expresiones complejas

3.1 Operadores aritméticos#

Los operadores aritméticos permiten realizar cálculos matemáticos. Python respeta las reglas matemáticas tradicionales.

Operadores disponibles:

  • + suma

  • - resta

  • * multiplicación

  • / división

  • // división entera

  • % módulo (resto)

  • ** potencia

Ejemplos básicos:

5 + 3, 5 - 3, 5 * 3, 5 / 3

5 // 3, 5 % 3, 2 ** 4

División entera y módulo#

  • // devuelve solo la parte entera

  • % devuelve el resto

Son muy útiles en algoritmos, por ejemplo para determinar si un número es par:

numero = 14
es_par = (numero % 2 == 0)
es_par

3.2 Operadores lógicos#

Los operadores lógicos permiten combinar condiciones.

Operadores:

  • not: negación

  • and: conjunción

  • or: disyunción

Estos operadores trabajan con valores booleanos (True, False).

Ejemplos:

not True, True and False, True or False

3.3 Operadores de comparación#

Permiten comparar valores y devuelven un booleano.

Operadores:

  • == igual que

  • != distinto que

  • < menor que

  • > mayor que

  • <= menor o igual que

  • >= mayor o igual que

Ejemplos:

3 == 3, 3 != 4, 3 < 5, 3 >= 3

Comparación de cadenas#

Python compara cadenas según el orden ASCII.

Ejemplo:

  • 'a' > 'A' es True porque las minúsculas tienen mayor valor ASCII.

'a' > 'A', 'Python' == 'python'

3.4 Prioridad de operadores#

Python evalúa las expresiones siguiendo un orden específico:

  1. Paréntesis ()

  2. Potencias **

  3. Multiplicación, división, módulo, división entera

  4. Suma y resta

  5. Comparaciones

  6. not

  7. and

  8. or

Ejemplo complejo:

resultado = 2 + 3 * 4 > 10 and not False
resultado

Desglose:

  • 3 * 4 → 12

  • 2 + 12 → 14

  • 14 > 10 → True

  • not False → True

  • True and True → True

3.5 Expresiones#

Una expresión combina valores, variables y operadores para producir un resultado.

Ejemplo clásico:

a = 5
b = 3
c = (a + b) * 2
c
